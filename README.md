# Challenge-04-Looplab

This challenge contains about my project Looplab.

problem 

Create a C program called LOOPLAB to analyse daily expenses. Repeatedly read expense amounts until the user enters 0. For each positive
amount, classify it using the rules below, update counts and totals, and finally display a summary. Use loops, conditional statements, arithmetic
operators, and variables. Do not use arrays, functions, or string.
