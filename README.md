# Challenge-04-Looplab

This challenge contains about my project Looplab.

problem 

Create a C program called LOOPLAB to analyse daily expenses. Repeatedly read expense amounts until the user enters 0. For each positive
amount, classify it using the rules below, update counts and totals, and finally display a summary. Use loops, conditional statements, arithmetic
operators, and variables. Do not use arrays, functions, or strings.

Algorithm 


1. Start the program and initialize all counts and totals to zero.
2. Read an expense amount repeatedly using a loop.
3. If the amount is 0, stop the loop. If it is negative, display an error and ignore it.
4. If the amount is positive, increment the valid expense count and total, then classify it as Small, Medium, or Large and update the corresponding count and total.
5. After the loop ends, display the valid expense count, total, category-wise counts and totals, and average. If there are no valid expenses, display a suitable message.
6. Stop the program.
